About

Immersive 3D environments, built for the open web.

I build responsive web applications, interactive browser experiences and WebXR projects — combining immersive 3D environments with modern web technology.

I recently completed a Level 3 Certificate in Coding Practices, and I'm continuing to build on that — developing my skills in secure web development, application hardening and production deployment. My current focus is preparing web applications for commercial payment integration, which involves investigating security standards and applying secure development practices throughout.

Alongside this, I'm studying a Level 3 qualification in Cybersecurity, with a particular focus on the OWASP principles — the Open Worldwide Application Security Project's industry-standard framework, best known for its Top 10 catalogue of the most critical web application security risks and the defensive practices used to mitigate them. This study feeds directly into how I approach authentication, data protection and application hardening in my development work.

I also actively research AI-assisted software development — including Retrieval-Augmented Generation (RAG), Model Context Protocol (MCP), context engineering and sequential multi-agent workflows. My aim is to use AI as a development tool while retaining human oversight of architecture, security, testing and code quality.
