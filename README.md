# TEZZ — Terence Honeyford

Personal portfolio & CV site. Web Developer / XR.

## Pages

- **`index.html`** — Main portfolio site (GSAP animations, WebXR / A-Frame / WebGL showcases, colour themes)
- **`cv.html`** — Curriculum Vitæ
- **`graphic-design-portfolio.html`** — Graphic design / branding showcase

## Assets

- `gsap.min.js` — GSAP animation library (vendored locally)
- `Assets/` — 3D / render images

## Usage

No build step — it's a static site. Just open `index.html` in a browser, or serve the folder:

```sh
python -m http.server 8000
```
